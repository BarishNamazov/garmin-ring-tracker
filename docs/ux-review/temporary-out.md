# Temporary-out main screen (2h50 / 3h10, 42/47/51 mm)

## P1
1. **The 3-hour threshold is invisible until crossed.** At 2h50 the screen is structurally identical to 0h05. Fix: thin progress ring toward 3 h (amber, red at/after 3:00) plus a secondary line "10m left" / "10m over" (or "Back in by 15:20"). Elapsed stays the hero; remaining/over is the decision-maker.
2. **Everything turns red at 3h10, so nothing stands out.** Fix: red only for state (title + number); body copy white with the action line bold: **Reinsert now** / Backup contraception for 7 days.
3. **Layout jumps when the threshold is crossed** (title/number shift ~35 px; 42 mm third line ~40 px from arc). Fix: fixed title/number positions in both states; reserve a two-line body zone; cut over-limit copy to two lines.

## P2
4. **Dimmed arc not dimmed enough; white marker is the brightest small thing.** Fix: cycle arc at ~25–30% luminance (desaturated), marker dimmed or hidden while out; if a 3 h ring exists, it is the only bright arc.
5. **Copy.** "Put it back in" → "Reinsert within 10m" (or "10m left · back in by 15:20"). "Out over 3h. Reinsert now. Use backup 7 days." → two lines: "Reinsert now" / "Backup contraception · 7 days". No trailing periods.
6. **Units typography.** Uneven spacing around "h"; composite off optical centre. Fix: thin space both sides of "h", trim gap before minutes, centre on ink bounds; units on a slightly higher baseline.

## P3
7. Amber pre-threshold reads as permanent warning; with a progress ring, number white for first ~2 h, amber last 30–60 min, red after 3 h.
8. Show "Out since 12:30" (small grey line).
9. Cross-size consistency otherwise good.

**Verdict:** clean and unambiguous count-up, but fails its brief: nothing says the cliff is 10 minutes away, and uniform red buries the instruction. Add a 3 h ring + "Xm left/over", reserve red for state, freeze layout across the threshold.
