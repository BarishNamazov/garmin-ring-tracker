# Main menus (ring in / ring-free / temporarily out / no cycle)

## P1
1. **"Remove ring" next to "Ring out" is indistinguishable** (both = ring leaves body). Fix: 1 **Remove ring** — sub-label *Start ring-free week*; 2 **Ring out briefly** — sub-label *Back in within 3 h*. Never ship the two bare labels side by side.
2. **"Remove ring" while temporarily out is a wording logic error.** Fix: 1 **Reinsert ring**; 2 **Keep out, start ring-free week** (or **Don't reinsert** — sub-label *Start ring-free week*).
3. **No-cycle state can't onboard a user whose ring is already in.** Fix: 1 **Insert ring now**; 2 **Ring already in…** (date picker); drop History from this state.

## P2
4. "Edit dates" vague → **Edit removal time** (ring-free), **Edit insertion time** (ring in).
5. Verb-first consistency: "Ring back in" → **Reinsert ring**.
6. Title "Menu" is dead weight → state-bearing title (**Ring in · day 12**, **Ring-free · day 3**, **Ring out · 0:42**, **No cycle**) or "Ring Tracker".
7. Logging vs reminding ambiguity → sub-label *Logs current time* on primary actions (or "…now").

## P3
8. Early insertion in ring-free deserves a guard confirmation ("Day 3 of 7 — insert early?").
9. Only two items visible at once: keep ≤4 items per state; Settings/History last.
10. Temporarily-out: add **Undo ring out** (sub-label *Remove this entry*).

## Proposed final menus
- Ring in: Remove ring · Ring out briefly · Edit insertion time · History
- Ring-free: Insert ring · Edit removal time · History
- Temporarily out: Reinsert ring · Keep out, start ring-free week · Undo ring out
- No cycle: Insert ring now · Ring already in… · Settings

**Verdict:** structure sound, first item right everywhere; fix items 1–3 before release, 4–7 same pass.
